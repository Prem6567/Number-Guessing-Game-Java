🎯 Number Guessing Game – Java

A console-based Number Guessing Game developed using Core Java. The player selects a difficulty level and tries to guess a randomly generated number with helpful hints.

🚀 Features

- 🎲 Random number generation
- 🎮 Three difficulty levels
  - Easy: 1–50
  - Medium: 1–100
  - Hard: 1–500
- 🔢 Attempt tracking
- 💡 Higher/Lower hints
- ✅ Input validation
- 🔄 Play Again option
- ⭐ Performance evaluation
- 🧩 Modular programming using Java methods

🛠️ Technologies Used

- Java
- Core Java
- "Scanner"
- "Random"
- Loops
- Conditional Statements
- Methods
- Input Validation

▶️ How to Run

1. Install Java JDK on your computer.
2. Clone or download this repository.
3. Open the project in any Java IDE or terminal.
4. Compile the program:

javac NumberGuessingGame.java

5. Run the program:

java NumberGuessingGame

🎮 How to Play

1. Select a difficulty level.
2. Enter your guessed number.
3. The game tells you whether your guess is Too High or Too Low.
4. Continue guessing until you find the correct number.
5. The game displays your total attempts and performance.
6. Choose whether you want to play again.
